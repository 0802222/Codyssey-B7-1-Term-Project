# EE-19: 실제 AI 설명 품질 증빙

같은 질문의 설명 수준 차이와 후속 질문의 문맥 유지를 실제 AI 답변으로 확인했습니다.
**최신 5개 샘플에서 수준 차이·문맥 유지와 해요체·일반 텍스트 출력을 확인했습니다.**
이전 샘플의 지도 예시·비유 불일치·말투·Markdown 문제도 원문과 검토 기록에 남겼습니다.
Fake·모의 HTTP 테스트는 처리 흐름의 검증이며, 생성 문장의 품질 증빙과 구분합니다.
문서와 샘플은 B 담당 영역인 `app/chat/`에 모았습니다. 위치는 팀장 리뷰에서 확인합니다.

## 시나리오

| 순서 | 사례 ID | 대화 | 수준 | 질문 | 확인할 것 |
|---|---|---|---|---|---|
| 1 | A-easy | A, 새 대화 | easy | API가 무엇인지 설명해줘. | 쉬운 말·비유 |
| 2 | B-beginner | B, 새 대화 | beginner | 같은 질문 | 기본 용어 정의·작동 흐름 |
| 3 | C-advanced | C, 새 대화 | advanced | 같은 질문 | 원리·전제·한계 |
| 4 | C-easier | C 유지 | easy | 더 쉽게 | 앞의 API 설명을 기억하고 이번 easy 적용 |
| 5 | C-example | C 유지 | easy | 예시 하나 더 | 같은 개념에 새로운 예시 |

초기 세 답변은 각각 새 대화로 생성하여 앞의 수준·답변이 영향을 주지 않게 합니다.
후속 질문은 C에 저장된 완료 턴을 사용합니다. 현재 수준은 이전 advanced가 아닌 easy입니다.

## 수집 도구

`quality_check.py`는 임시 SQLite에서 EE-13의 `answer_question()`을 호출합니다.
기존 소유권·저장·문맥·한도·provider 흐름을 재사용하고, 종료할 때 임시 DB를 삭제합니다.
이 기록의 검증 범위는 채팅 서비스입니다. 브라우저·실제 로그인 UI와 배포 환경은 별도 검증 대상입니다.

```bash
uv run --locked python -m app.chat.quality_check \
  --live \
  --env-file /본인/프로젝트/.env \
  --output app/chat/samples/ee-19-실행일.json
```

- 키는 Git에서 제외되는 로컬 `.env`에만 둡니다. 명령 인자나 출력 파일에 키를 적지 않습니다.
- `--live`를 명시한 수동 실행만 실제 Anthropic provider를 사용합니다. 기본 테스트는 실제 AI를 호출하지 않습니다.
- 한 실행은 최대 5회이며 SDK 자동 재시도를 사용하지 않습니다. 실패하면 중단하고 완료한 기록을 보존합니다.
- 기존 출력 파일은 덮어쓰지 않습니다. 재실행은 별도 파일을 사용합니다.
- 질문·답변 원문은 증빙 파일에 저장합니다. 수집 중 SDK 디버그 설정이 켜져도 로그는 차단합니다.

샘플에는 실행 시각, 요청 모델과 실제 응답 모델, 현재 수준, 질문·답변, 실제 전달한 시스템 지침·메시지,
문맥·출력 상한 설정, 프롬프트·문맥 코드의 SHA-256을 기록합니다.
키·쿠키·이메일·DB 경로·환경 파일 경로는 포함하지 않습니다.
JSON의 `collection_status=completed`는 수집 완료이며 품질 통과를 뜻하지 않습니다.
`quality_review=not_performed`는 수집 시점 값이고, 아래 표가 별도의 수동 품질 검토 기록입니다.

### 지도 예시의 한계

C-example에는 “공식 문서 기준”, “개념 이해용으로 단순화”라는 각주가 붙었습니다.
이 문구 자체가 본문의 정확성을 검증하지는 않습니다.
[Kakao 지도 Web 가이드](https://apis.map.kakao.com/web/guide/)는 브라우저에서 SDK로 지도 객체를 생성하는 흐름을 설명하며,
[이미지 지도(StaticMap)](https://apis.map.kakao.com/web/sample/staticMap/)는 별도 예제입니다.
따라서 “카카오가 지도를 그려 돌려준다”를 지도 API 전체의 동작으로 판정하지 않았습니다.

사람이 고쳐 설명한다면 “내 앱이 카카오 지도 SDK를 이용해 화면에 지도를 표시해요”가 더 정확합니다.
이 문장은 검토자의 제안이고 실제 AI 응답 원문에는 덧붙이지 않았습니다.
특정 서비스의 사용법은 공식 문서로 확인해야 하며, 이 샘플은 API 개념 설명의 증빙입니다.

한 주제의 소수 샘플은 모든 질문의 정확성을 보장하지 않습니다.
모호한 질문·문맥 없는 후속 지시의 확인 질문은 기존 프롬프트·단위 테스트의 범위이며 이번 실제 5개 사례에는 포함되지 않습니다.
